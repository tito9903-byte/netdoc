# Glosario

- **NetDoc:** interfaz web operativa del proyecto.
- **NetBox:** fuente oficial del inventario técnico.
- **Dispositivo / interfaz / cable:** equipo, punto de conexión y vínculo físico del inventario.
- **Rack / unidad de rack:** bastidor y su unidad vertical de ocupación.
- **Patch panel / puerto frontal / puerto trasero:** elementos físicos Planificado para terminación de cableado.
- **Desarrollo / producción:** entornos separados `develop`/8101 y `main`/8100.
- **Despliegue / rollback:** actualización controlada / restauración del commit previo.
- **Rama / pull request:** línea Git / propuesta revisable para integrarla.
- **ADR:** registro de una decisión de arquitectura.
- **Fuente oficial:** documento o código prioritario para un tipo de información.
- **Auditoría / rol / permiso:** trazabilidad, agrupación de autorizaciones y autorización concreta; Planificado internamente.
