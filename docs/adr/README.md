# ADR de NetDoc

Un ADR registra una decisión arquitectónica y sus consecuencias. Créelo al cambiar arquitectura, límites, integración o estrategia persistente. Numérelo secuencialmente `NNNN-titulo-kebab.md`. Estados permitidos: **Propuesto**, **Aceptado**, **Reemplazado**, **Rechazado**, **Obsoleto**. Para reemplazar, cree un ADR nuevo y enlace ambos.

Plantilla: número, título, estado, fecha real, contexto, problema, decisión, alternativas, consecuencias positivas/negativas, riesgos, mitigaciones y referencias internas.
